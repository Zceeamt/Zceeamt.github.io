# Abdulhakim Amtouti — Engineering Portfolio

Personal engineering portfolio for an Electronic and Electrical Engineering student at UCL, covering embedded systems, PCB design, FPGA development, robotics and power electronics.

**Live site:** [zceeamt.github.io](https://zceeamt.github.io)

## Featured projects

- [Custom STM32 drone flight controller](https://github.com/Zceeamt/custom-stm32-drone-flight-controller) — four-layer STM32H743 flight-controller PCB, custom 3D-printed airframe, Betaflight bring-up and successful outdoor flight testing.
- [Four-layer BLDC electronic speed controller](https://github.com/Zceeamt/four-layer-bldc-esc) — sensorless three-phase motor controller using an STM32F051, DRV8300 gate driver, MOSFET power stage and back-EMF sensing.
- [FPGA UART transmitter](https://github.com/Zceeamt/fpga-uart-transmitter) — SystemVerilog 8N1 UART transmitter on a Cyclone IV FPGA, verified against an Arduino receiver.
- [Dual-output DC-DC power supply](https://github.com/Zceeamt/dual-output-dc-dc-power-supply) — MC34063A-based 5 V and 12 V converters with current limiting and Multisim verification.
